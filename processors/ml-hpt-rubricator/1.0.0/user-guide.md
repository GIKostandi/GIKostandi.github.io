# Описание

Обработчик для рубрикации документов, работающий на основе модели: https://github.com/wzh9969/HPT.
Обработчик назначает рубрики документу, определенные моделью.

# Конфигурация обработки

Конфигурация обработки представлена формой, в которой можно задать параметры обработки.

* **Идентификатор рубрикатора** - пользовательский идентификатор рубрикатора с рубриками, определяемыми моделью.
